## Summary

Video-understanding experience should show that you can model time, not only images. Strong evidence covers frame sampling, temporal windows, tracking, annotation, latency, and evaluation by event timing.

## Example framing

A useful project story might explain how sliding-window inference detected actions in long videos, how overlapping windows were merged, how false triggers were reduced, and how latency was kept within product constraints.

## Experience map

Map each story to the temporal unit: frame, clip, track, event, or stream. Good video examples explain timing errors, occlusion, camera motion, and latency rather than treating video as image classification with extra frames.
