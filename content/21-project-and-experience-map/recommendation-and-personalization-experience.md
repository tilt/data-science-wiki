## Summary

Recommendation and personalization experience should show that you can build ranking systems under sparse feedback, changing inventories, latency constraints, and measurable user impact. The page maps portfolio evidence to canonical wiki concepts.

## Evidence to document

Useful project evidence includes the recommendation objective, user and item types, feedback signals, candidate sources, ranking model, feature pipeline, evaluation design, online experiment results, and monitoring plan. Keep confidential implementation details out, but preserve the technical decision structure.

## Experience framing

A strong experience story explains the baseline, the main bottleneck, the chosen architecture, and the tradeoff. For example: popularity baseline was robust for new users; collaborative signals improved known-user relevance; content features improved item cold start; diversity rules reduced repetitive recommendations.
