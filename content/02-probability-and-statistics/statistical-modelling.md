# Statistical Modelling

## Summary

Statistical modelling represents data as observations generated by a stochastic process. The goal is not only prediction, but also uncertainty, assumptions, and interpretable structure.

## Model structure

A statistical model usually specifies a response variable, covariates, parameters, an error distribution, and assumptions about sampling or dependence. A simple regression model can be written as

$$
y_i = x_i^\top \beta + \epsilon_i,\quad \epsilon_i \sim \mathcal{N}(0,\sigma^2)
$$

The fitted parameters are useful only relative to the model: changing the likelihood, link function, sampling scheme, or missing-data assumptions changes what the estimates mean.

## Worked example

To estimate whether a treatment changes conversion, define the estimand, collect comparable treated and control observations, choose a model for conversion probability, and report both the estimated effect and uncertainty interval. The same point estimate can support different decisions depending on uncertainty and cost.

## Caveats

- Separate the estimand, estimator, estimate, and uncertainty statement.
- Check independence, sampling, stationarity, and missing-data assumptions.
- Report uncertainty and practical significance, not only a point estimate.
- Do not interpret coefficients causally unless the design supports a causal claim.
