# Bm25

## Summary

BM25 is a lexical ranking function that scores documents by query term matches, term rarity, term frequency saturation, and document-length normalization.

## Step-by-step example

A query for "matrix factorization implicit feedback" will reward documents containing those terms, especially rarer terms, without requiring embeddings.

## Common failure modes

- Optimizing Bm25 on aggregate relevance while missing important query classes and hard negatives.
- Evaluating retrieval components separately when the user sees the combined retrieval, reranking, filtering, and presentation pipeline.
- Ignoring index freshness, permissions, latency, and failure behavior under empty or ambiguous queries.

- Confusing retrieval quality with downstream answer quality.
- Ignoring freshness, permissions, metadata filters, and operational latency.

## Mechanism

BM25 scores a document $d$ for query terms $q_i$ with term frequency saturation and document-length normalization:

$$
\operatorname{BM25}(q,d)=\sum_i \operatorname{IDF}(q_i)
\frac{f(q_i,d)(k_1+1)}{f(q_i,d)+k_1(1-b+b|d|/\operatorname{avgdl})}.
$$

It rewards matching rare query terms while preventing repeated terms from increasing the score without bound.
