# Evaluation

## Summary

Interview evaluation answers should start from the decision being supported, then connect metrics, data, uncertainty, slices, and failure severity. The goal is to show judgement, not metric memorization.

## Step-by-step example

For a RAG assistant, say you would evaluate retrieval, context construction, grounded answer quality, citations, abstention, latency, and severe errors separately.

## Answer pattern

For evaluation questions, state the decision first, then choose metrics, dataset, slices, uncertainty method, and failure review. A strong answer explains what would make you block a launch even if the headline metric improves.
