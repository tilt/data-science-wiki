## Recommended answer shape

1. Start with a direct one-sentence answer.
2. Define the key technical distinction.
3. Give a small concrete example.
4. Name the main limitation or failure mode.
5. Link the answer back to evaluation or production consequences.

## Maintenance rule

If a page primarily teaches a concept, keep it in the canonical subject area. If it primarily teaches how to answer a prompt, keep it in this interview section and link back to the canonical page.
