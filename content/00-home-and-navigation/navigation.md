## Summary

Navigation explains how to move through the wiki by task: learning, interview preparation, project storytelling, production design, or reference lookup. It complements the numbered taxonomy.

## Routes

Use subject indexes when studying a domain from first principles. Use interview pages when preparing concise answers. Use experience-map pages when translating project work into evidence. Use references when looking up terminology.

## Example

If preparing for a recommendation-system interview, start at the interview page, follow links to candidate generation and ranking, then use evaluation and online-experiment pages to strengthen the production answer.
