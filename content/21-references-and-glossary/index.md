# References and Glossary

## Summary

References and Glossary is the wiki's lookup and citation spine. It collects definitions, notation, acronyms, bibliography keys, and further-reading routes so concept pages can stay focused while still remaining traceable.

## Subtopics

- [References](references.md)
- [Glossary](glossary.md)
- [Notation](notation.md)
- [Acronyms](acronyms.md)
- [Further Reading](further-reading.md)

## How to use this section

- Use [Glossary](glossary.md) for short definitions of recurring terms.
- Use [Acronyms](acronyms.md) when a page uses abbreviated names.
- Use [Notation](notation.md) to interpret formulas consistently across math, forecasting, ML, and evaluation pages.
- Use [Bibliography](bibliography.md) to understand source keys in front matter.
- Use [Further Reading](further-reading.md) to choose next sources after the wiki overview.

## Maintenance expectations

Reference pages should be boring and stable. Add terms when they appear in several topic pages, keep definitions short, and link to canonical concept pages for depth. Bibliography keys should not be renamed casually because topic pages depend on them.
