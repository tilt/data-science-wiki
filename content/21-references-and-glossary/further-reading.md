# Further Reading

## Summary

Further reading routes point from wiki overviews to deeper material. Use them after reading the concise concept pages and identifying which subject needs more depth.

## Suggested routes

- Linear algebra and numerical methods: start with [Matrix Decompositions](../01-mathematical-foundations/matrix-decompositions.md) and [Singular Value Decomposition](../01-mathematical-foundations/singular-value-decomposition.md).
- Recommender systems: start with [Collaborative Filtering](../04-recommendation-systems/collaborative-filtering.md), [Matrix Factorization](../04-recommendation-systems/matrix-factorization.md), and [Evaluation of Recommenders](../04-recommendation-systems/evaluation-of-recommenders.md).
- Forecasting: start with [ARIMA](../05-time-series-and-forecasting/arima.md), [Backtesting](../05-time-series-and-forecasting/backtesting.md), and [Forecast Evaluation](../05-time-series-and-forecasting/forecast-evaluation.md).
- Generative AI: start with [RAG](../11-generative-ai/rag.md), [Tool Use and Function Calling](../11-generative-ai/tool-use-and-function-calling.md), and [RAG Evaluation](../11-generative-ai/rag-evaluation.md).
- Production ML: start with [ML System Lifecycle](../14-ml-engineering-and-mlops/ml-system-lifecycle.md), [Monitoring](../14-ml-engineering-and-mlops/monitoring.md), and [Golden Datasets](../17-experimentation-and-evaluation/golden-datasets.md).

## How to choose sources

Choose primary papers when you need the original formulation, official documentation when implementing an API, and textbooks or standards when learning stable foundations. For fast review, read the wiki page first, then one primary or authoritative source.

## Maintenance

Keep this page as a route map, not a dumping ground. If a source becomes important to multiple pages, add it to [references](references.md) or the central [bibliography](bibliography.md).
