# Further Reading

## Summary

Further reading routes point from wiki overviews to deeper material. Use them after reading the concise concept pages and identifying which subject needs more depth.

## Suggested routes

These follow the wiki's section order; each names a good entry point for depth in that area.

- Linear algebra and numerical methods: start with [Matrix Decompositions](../01-mathematical-foundations/matrix-decompositions.md) and [Singular Value Decomposition](../01-mathematical-foundations/singular-value-decomposition.md).
- Probability and statistics: start with [Bayes Theorem](../02-probability-and-statistics/bayes-theorem.md), [Maximum Likelihood](../02-probability-and-statistics/maximum-likelihood.md), and [Hypothesis Testing](../02-probability-and-statistics/hypothesis-testing.md).
- Classical machine learning: start with [Linear Models](../03-classical-machine-learning/linear-models.md), [Gradient Boosting](../03-classical-machine-learning/gradient-boosting.md), and [Model Selection](../03-classical-machine-learning/model-selection.md).
- Recommender systems: start with [Collaborative Filtering](../04-recommendation-systems/collaborative-filtering.md), [Matrix Factorization](../04-recommendation-systems/matrix-factorization.md), and [Evaluation of Recommenders](../04-recommendation-systems/evaluation-of-recommenders.md).
- Forecasting: start with [ARIMA](../05-time-series-and-forecasting/arima.md), [Backtesting](../05-time-series-and-forecasting/backtesting.md), and [Forecast Evaluation](../05-time-series-and-forecasting/forecast-evaluation.md).
- Deep learning: start with [Neural Network Fundamentals](../06-deep-learning/neural-network-fundamentals.md), [Backpropagation](../06-deep-learning/backpropagation.md), and [Transformers](../06-deep-learning/transformers.md).
- Reinforcement learning: start with [Markov Decision Processes](../07-reinforcement-learning/markov-decision-processes.md), [Temporal Difference Learning](../07-reinforcement-learning/temporal-difference-learning.md), and [Policy Gradients and Actor-Critic](../07-reinforcement-learning/policy-gradients-and-actor-critic.md).
- Natural language processing: start with [Language Modelling](../08-natural-language-processing/language-modelling.md), [Tokenization](../08-natural-language-processing/tokenization.md), and [Named Entity Recognition](../08-natural-language-processing/named-entity-recognition.md).
- Computer vision: start with [Image Classification](../09-computer-vision/image-classification.md), [Object Detection](../09-computer-vision/object-detection.md), and [Semantic Segmentation](../09-computer-vision/semantic-segmentation.md).
- Generative AI: start with [RAG](../11-generative-ai/rag.md), [Tool Use and Function Calling](../11-generative-ai/tool-use-and-function-calling.md), and [RAG Evaluation](../11-generative-ai/rag-evaluation.md).
- Information retrieval and search: start with [BM25](../12-information-retrieval-and-search/bm25.md), [Dense Retrieval](../12-information-retrieval-and-search/dense-retrieval.md), and [Ranking and Retrieval Metrics](../12-information-retrieval-and-search/ranking-and-retrieval-metrics.md).
- Data engineering: start with [Data Pipelines](../13-data-engineering/data-pipelines.md), [ETL and ELT](../13-data-engineering/etl-and-elt.md), and [Data Quality](../13-data-engineering/data-quality.md).
- Production ML: start with [ML System Lifecycle](../14-ml-engineering-and-mlops/ml-system-lifecycle.md), [Monitoring](../14-ml-engineering-and-mlops/monitoring.md), and [Golden Datasets](../17-experimentation-and-evaluation/golden-datasets.md).
- Experimentation and evaluation: start with [Offline Evaluation](../17-experimentation-and-evaluation/offline-evaluation.md), [A/B Testing](../17-experimentation-and-evaluation/a-b-testing.md), and [Statistical Significance](../17-experimentation-and-evaluation/statistical-significance.md).
- Responsible AI: start with [Fairness](../18-responsible-ai-safety-and-governance/fairness.md), [Explainability](../18-responsible-ai-safety-and-governance/explainability.md), and [Governance of Model and Knowledge Base Changes](../18-responsible-ai-safety-and-governance/governance-of-model-and-knowledge-base-changes.md).

## How to choose sources

Choose primary papers when you need the original formulation, official documentation when implementing an API, and textbooks or standards when learning stable foundations. For fast review, read the wiki page first, then one primary or authoritative source.

## Maintenance

Keep this page as a route map, not a dumping ground. If a source becomes important to multiple pages, add it to [references](references.md) or the central [bibliography](bibliography.md).
