# Authoring Style

Use a flexible schema: structure follows the topic. The concept template is a menu, not a mandate. Prefer subtraction over padding; delete low-information sections instead of preserving a uniform page shape. Keep a section only when it says something specific to that page that a reader could not infer from a neighboring page.

Deletion test: copy the section body next to the same-named section on two sibling pages. If a reader could not tell which topic it belongs to, the section is filler and should be deleted or rewritten into topic-specific prose.
